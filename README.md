# Hi, I'm Ruoxi Zhao

Math PhD student at UC Riverside, advised by [Maziar Raissi](https://maziarraissi.github.io/). I design benchmarks and adversarial evaluation environments for LLM agents, and work on neural operators and Gaussian-process methods for PDEs and scientific modeling. I like problems that need both mathematical depth and end-to-end engineering.

**Latest:** *Backtrader-Bench: Benchmarking LLM Agents on Algorithmic Trading with Self-Generated MCQs* (Zhao and Raissi), FinLLM Workshop @ IJCAI 2026.
[arXiv](https://arxiv.org/abs/2608.11232) · [Code and data](https://github.com/rzhao999/Backtrader-Bench)

## Research interests

- **Evaluating LLM agents.** Contamination-resistant, self-verifying benchmarks; generator/solver arenas that mine hard questions without a human in the loop; the gap between tool-using and tool-free agents.
- **LLM reasoning.** Reasoning diversity in Mixture-of-Experts models via inference-time routing noise (research intern, Voaige, summer 2026).
- **AI for science and healthcare.** In-Context Operator Networks and GP methods for PDEs; materials optimization from X-ray diffraction data (LBNL); surgical tool localization in endoscopic video (Argonne, MICCAI SurgToolLoc 2023, team ANL-Surg, 3rd place).
